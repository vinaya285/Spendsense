# SpendSense AI

AI-powered intent-based expense tracking fintech app.

- Intent-based expense tracking
- Firebase Authentication
- Firestore Database
- AI Spending Insights
- Transaction History
- Analytics Dashboard
- Responsive UI

## Tech Stack

- React.js
- Tailwind CSS
- Firebase
- Firestore
- Gemini AI
- Recharts
